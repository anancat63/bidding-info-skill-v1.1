# 乌海市政府采购商机查询 Skill

> 实时采集**内蒙古自治区政府采购网**乌海市的招标公告与采购意向，并支持按公司业务范围由 AI 打分排序，帮助快速发现值得跟进的投标商机。

## 功能特性

- **两类信息**：招标公告（公开招标 / 询价 / 竞争性磋商）与采购意向公开（正式招标前的预告）
- **四种查询模式**：招标公告、采购意向各提供「原始列表（JSON）」与「AI 评分排序」两个版本
- **零第三方依赖**：仅使用 Python 标准库（urllib）实现，无需 pip 安装任何包
- **实时采集**：直接调用官网列表接口，数据与官网同步
- **自动过滤**：已截止 / 已过期的项目自动剔除，并自动计算剩余天数或剩余月数
- **智能评分**：排序版读取 `config/company.txt` 中的公司业务范围，由 Agent 对每个项目按 0–100 分匹配度打分并排序
- **信息提取**：自动从采购意向描述中提取预算金额（万元）与预计采购月份，清理公文套话

## 触发场景

当用户向 Agent 提出以下问题时使用本技能：

- 乌海最近有什么招标公告 / 采购信息？
- 有没有适合我们公司的项目 / 商机？
- 查一下采购意向 / 招标公告
- 有什么能做的标？能做什么项目？
- 按匹配度 / 业务范围排序推荐项目

触发词：招标公告、采购意向、政府采购、商机、投标、标书、乌海招标、有什么标、能做什么项目。

## 环境要求

- Python 3（仅使用标准库，无需安装第三方依赖）
- 可以正常访问 https://www.ccgp-neimenggu.gov.cn 的网络环境

## 安装

将本仓库克隆或下载到 Agent 的技能目录，使 `SKILL.md` 位于技能根目录即可：

```bash
git clone https://github.com/anancat63/bidding-info-skill-v1.1.git
```

Agent 通过网络检索到本仓库后，按其技能安装流程加载即可；`SKILL.md` 头部已声明运行依赖（`bins: ["python3"]`）。

## 使用方式

### 四种查询模式

| 用户意图 | 执行命令 |
|---------|---------|
| 查招标公告，不排序 | `python3 {baseDir}/scripts/bids.py` |
| 查招标公告，按业务匹配排序 | `python3 {baseDir}/scripts/bids_ranked.py` |
| 查采购意向，不排序 | `python3 {baseDir}/scripts/intentions.py` |
| 查采购意向，按业务匹配排序 | `python3 {baseDir}/scripts/intentions_ranked.py` |

其中 `{baseDir}` 为技能根目录占位符；在终端直接运行时把它替换为实际路径即可。

### 命令行参数

| 参数 | 说明 | 默认值 |
|------|------|--------|
| `--top N` | 只取前 N 条，`0` 表示全部 | `0` |
| `--page-size N` | 从官网采集的条数 | `20` |
| `--region CODE` | 行政区划编码，乌海市为 `150301` | `150301` |

示例：

```bash
# 只看前 10 条招标公告
python3 scripts/bids.py --top 10

# 采集 50 条采购意向，并由 AI 按业务匹配度评分排序
python3 scripts/intentions_ranked.py --page-size 50
```

脚本也可以脱离 Agent 在终端直接运行：不排序版输出 JSON；排序版输出「评分任务说明 + 公司业务范围 + 项目编号列表」文本，由 AI 读取后完成打分。

## 输出说明

**招标公告（bids.py，JSON）**：包含官网总数、返回条数，以及每条项目的标题、地区、采购方式、发布日期、截止时间、剩余天数、详情链接。

**采购意向（intentions.py，JSON）**：包含标题、地区、采购单位、发布日期、预计采购时间、预算（万元）、项目描述、详情链接。

**排序版（*_ranked.py）**：输出公司业务范围、评分规则和带编号的项目列表，由 Agent 逐项打分后整理为 Markdown 表格。评分分档：

| 分数区间 | 含义 | 跟进建议 |
|---------|------|---------|
| 80–100 | 高度匹配，属于核心业务 | 立即跟进 |
| 60–79 | 比较匹配，公司有能力承接 | 重点关注 |
| 40–59 | 部分相关 | 作为储备 |
| 0–39 | 关联度低 | 不建议投入精力 |

结果渲染时，剩余时间 ≤3 天的项目标注 🔴 紧急、≤7 天标注 🟡 关注；已截止 / 已过期的项目已由脚本自动过滤，不会出现。

## 自定义配置

- **更换公司业务范围**：编辑 `config/company.txt`，写入本公司主营业务即可，排序版会自动读取并作为评分依据。当前文件内为「乌海数字产业发展集团」的业务范围，偏向软件开发、信息系统集成、人工智能、大数据、物联网、网络安全、数字视频监控等方向。
- **更换地区**：通过 `--region` 参数传入其他行政区划编码（本技能仅在内蒙古自治区政府采购网的编码体系下测试，乌海市 = `150301`）。

## 能力边界

- 数据源**仅限**内蒙古自治区政府采购网（ccgp-neimenggu.gov.cn）；
- 地区**仅限乌海市**（regionCode=150301），不支持其他省份、其他盟市；
- 不支持关键词搜索，只能按官网列表顺序获取；
- 数据为实时采集，遇到网络错误或官网接口调整时可能失败，请稍后重试或检查接口是否变更。
